Jev is TypeSafe AI's first System One model — a frontier decision engine optimized for fast, typed, calibrated judgments (Choice / Score / Noul) instead of free-form text generation. Typical latency 70–500 ms · ~$0.042 / M input tokens · output tokens free.

Why this exists

Within 72 hours of launch the community produced browser agents booking flights in ~7 s for under $0.004, trading bots deciding every ~300 ms, computer-use agents at $0.0002 per step, plus guardrails, code reviewers, drones and games. This index helps you find the ones worth reading.
